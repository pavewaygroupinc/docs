Pursar provides a fully functional, live cloud sandbox environment where you can safely test every payment rail, telecom operator response, and business API without moving real money.

---

## Sandbox Endpoints & Authentication

| Resource | Sandbox (Test Mode) | Production (Live Mode) |
| :--- | :--- | :--- |
| **API Base URL** | `https://api.viarosandbox.com/v1` | `https://api.pursar.com/v1` |
| **Hosted Checkout** | `https://checkout.viarosandbox.com/pay/{session_id}` | `https://checkout.pursar.com/pay/{session_id}` |
| **Business Dashboard** | `https://business.viarosandbox.com` | `https://business.pursar.com` |
| **Secret API Keys** | Starts with `sk_test_...` | Starts with `sk_live_...` |
| **Public / Publishable Keys** | Starts with `pk_test_...` | Starts with `pk_live_...` |
| **Webhook Secrets** | Starts with `whsec_...` | Starts with `whsec_...` |

> [!IMPORTANT]
> All requests to the sandbox API must authenticate with your test secret key (`sk_test_...`) using HTTP Basic Auth (`-u sk_test_...:`) or a Bearer token (`Authorization: Bearer sk_test_...`). Test keys and live keys are cryptographically separated; test keys cannot modify live data.

## Simulating and Verifying Webhooks

During local development, you can forward Pursar sandbox webhooks to your local development machine using [ngrok](https://ngrok.com) or [webhook.site](https://webhook.site):

```bash
# Start your local server on port 3000
npm run dev

# Expose port 3000 to the public web
ngrok http 3000
```

1. Copy your ngrok HTTPS forwarding URL (e.g. `https://a1b2c3d4.ngrok-free.app/api/webhooks`).
2. Add this URL under **Developers → Webhooks** in your [Business Dashboard](https://business.viarosandbox.com/developers/webhooks).
3. Copy the signing secret (`whsec_...`) and add it to your local environment variables.
4. Trigger test charges using `POST /v1/charges/mobile-money` or `POST /v1/checkout/sessions` and verify that your local endpoint receives and validates the `X-Pursar-Signature` header.
