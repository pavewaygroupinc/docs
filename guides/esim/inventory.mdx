title: "eSIM Inventory"
description: "Browse and query global and regional cellular data eSIM packages for reselling."
---

The Pursar eSIM API allows travel platforms, airlines, and fintech apps to query and resell global high-speed cellular data packages across 140+ countries.

---

## Browsing Packages

### 1. By Country
Fetch available cellular packages for a specific ISO country code:

```bash
curl -X GET https://api.viarosandbox.com/v1/esim/countries/CM/packages \
  -u sk_test_live_secret_key_12345:
```

### 2. By Region / Continent
Query regional packages that cover multiple countries (e.g., Africa, Europe, North America):

```bash
curl -X GET https://api.viarosandbox.com/v1/esim/continents/africa/packages \
  -u sk_test_live_secret_key_12345:
```

### 3. Global Packages
List global data plans that roam seamlessly across 100+ countries:

```bash
curl -X GET https://api.viarosandbox.com/v1/esim/global \
  -u sk_test_live_secret_key_12345:
```
