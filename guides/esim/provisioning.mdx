---
title: "eSIM Purchase & Provisioning"
description: "Order, collect payment, and instantly provision QR-code cellular profiles for your customers."
---

Reselling an eSIM profile via Pursar is a streamlined 3-step workflow: reserve inventory, collect payment, and provision the cellular SM-DP+ profile.

---

## Step 1: Create an eSIM Order

Reserve the inventory and lock in the wholesale package price:

```bash
curl -X POST https://api.viarosandbox.com/v1/esim/orders \
  -u sk_test_live_secret_key_12345: \
  -H "Content-Type: application/json" \
  -d '{
    "package_id": "pkg_world_5gb_30d",
    "quantity": 1
  }'
```

### Response

```json
{
  "order_id": "esim_ord_0192384a_5512",
  "package_id": "pkg_world_5gb_30d",
  "amount": 12500,
  "currency": "XAF",
  "status": "pending_payment"
}
```

---

## Step 2: Collect Payment

Charge the customer using [Pursar Hosted Checkout](/guides/payments/web-integration) or the [Direct Mobile Money API](/guides/payments/overview) passing `order_id` as the `merchant_reference`.

---

## Step 3: Confirm Payment & Generate eSIM QR Code

Once payment succeeds, confirm the order to immediately provision the cellular profile:

```bash
curl -X POST https://api.viarosandbox.com/v1/esim/orders/confirm-payment \
  -u sk_test_live_secret_key_12345: \
  -H "Content-Type: application/json" \
  -d '{
    "order_id": "esim_ord_0192384a_5512",
    "payment_ref": "tx_9182374b12c8"
  }'
```

### Response

```json
{
  "order_id": "esim_ord_0192384a_5512",
  "status": "provisioned",
  "iccid": "8988211000001234567",
  "matching_id": "TEST-1234-5678",
  "smdp_address": "smdp.pursar.com",
  "activation_code": "LPA:1$smdp.pursar.com$TEST-1234-5678",
  "qr_code_url": "https://api.viarosandbox.com/v1/esim/qr/esim_ord_0192384a_5512.png"
}
```

Display the `qr_code_url` on screen or email it to the traveler for instant 1-click device installation.
