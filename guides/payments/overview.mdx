Pursar provides an enterprise-grade financial infrastructure for collecting payments globally, with deep native connectivity to Central and West African mobile money networks and international card schemes.

## Integration Approaches

Depending on your user experience requirements, Pursar supports three primary integration patterns:

```mermaid
graph TD
    A[Payment Collection in Pursar] --> B[1. Pursar Hosted Checkout]
    A --> C[2. Direct Mobile Money API]
    A --> D[3. Payment Links]

    B --> B1["Pre-built, branded payment page<br/>POST /v1/checkout/sessions<br/>Redirect to checkout.viarosandbox.com"]
    C --> C1["Custom in-app/server UI<br/>POST /v1/charges/mobile-money<br/>Direct STK push to phone"]
    D --> D1["No-code shareable links<br/>POST /v1/payment_links<br/>Share via WhatsApp, SMS, Email"]
```

| Approach | Best For | Implementation Effort |
| :--- | :--- | :--- |
| **Hosted Checkout** | E-commerce websites, SaaS platforms, digital checkouts. | Lowest (1 server API call + browser redirect) |
| **Direct Mobile Money API** | In-app mobile checkouts, POS terminals, custom headless billing. | Medium (Collect phone number on your frontend, charge from server) |
| **Payment Links** | Invoices, social commerce, WhatsApp/SMS payment requests. | Zero code (create via dashboard or single API call) |

## The Stripe-Standard Integration Flow

Pursar separates sensitive server-side charge orchestration from client-side confirmation.

```mermaid
sequenceDiagram
    autonumber
    actor Customer as Customer
    participant Merchant as Merchant Server
    participant Pursar as Pursar API (api.viarosandbox.com)
    participant Telco as Telecom / Card Network
    participant Webhook as Merchant Webhook Endpoint

    Merchant->>Pursar: POST /v1/checkout/sessions or /v1/charges/mobile-money (-u sk_test_...:)
    Pursar-->>Merchant: Returns Session URL or Pending Charge Object
    alt Hosted Checkout Flow
        Merchant-->>Customer: Redirect to checkout.viarosandbox.com/pay/{id}
        Customer->>Pursar: Selects payment method & authorizes
    else Direct Mobile Money Flow
        Pursar->>Telco: Triggers USSD Push to Customer Phone
        Telco-->>Customer: PIN Prompt on mobile screen
        Customer->>Telco: Authorizes with Mobile Money PIN
    end
    Telco-->>Pursar: Payment Confirmed (Webhook / Callback)
    Pursar->>Pursar: Credits Merchant Balance & Updates Ledger
    Pursar->>Webhook: Dispatches payment.succeeded / checkout.session.completed
    Webhook-->>Pursar: 200 OK
    Merchant-->>Customer: Renders Order Confirmation
```

## 1. Quickstart: Direct Mobile Money Charge

If you already have the customer's phone number and want to trigger an immediate USSD payment prompt on their phone (MTN MoMo, Orange Money, Moov, Express Union, etc.), use the Direct Mobile Money endpoint:

### Endpoint

```http
POST https://api.viarosandbox.com/v1/charges/mobile-money
Authorization: Basic base64(sk_test_...:)
Content-Type: application/json
Idempotency-Key: <unique-uuid>
```

<CodeGroup>
```bash cURL
curl -X POST https://api.viarosandbox.com/v1/charges/mobile-money \
  -u sk_test_live_secret_key_12345: \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $(uuidgen)" \
```

```python Python
import os
import uuid
import requests

api_key = os.getenv("PURSAR_SECRET_KEY", "sk_test_live_secret_key_12345")
base_url = "https://api.viarosandbox.com/v1"

response = requests.post(
    f"{base_url}/charges/mobile-money",
    auth=(api_key, ""),
    headers={
        "Content-Type": "application/json",
        "Idempotency-Key": str(uuid.uuid4()),
    },
    json={
        "amount": 25000,
        "currency": "XAF",
        "phone": "+237671234567",
        "customer_name": "Amara Diallo",
        "customer_email": "amara@example.com",
        "description": "Premium Service License #104",
        "merchant_reference": "ORD_2026_104",
        "fee_bearer": "merchant",
    },
)

charge = response.json()
print("Charge Status:", charge["status"], "Transaction ID:", charge["id"])
```

```javascript Node.js / TypeScript
import axios from 'axios';
import crypto from 'crypto';

const apiKey = process.env.PURSAR_SECRET_KEY || 'sk_test_live_secret_key_12345';
const baseUrl = 'https://api.viarosandbox.com/v1';

async function chargeMobileMoney() {
  const response = await axios.post(
    `${baseUrl}/charges/mobile-money`,
    {
      amount: 25000,
      currency: 'XAF',
      phone: '+237671234567',
      customer_name: 'Amara Diallo',
      customer_email: 'amara@example.com',
      description: 'Premium Service License #104',
      merchant_reference: 'ORD_2026_104',
      fee_bearer: 'merchant'
    },
    {
      auth: { username: apiKey, password: '' },
      headers: {
        'Content-Type': 'application/json',
        'Idempotency-Key': crypto.randomUUID()
      }
    }
  );

  return response.data;
}
```

## 2. Server-Side Verification

After a charge is initiated or when a customer returns from checkout, verify the transaction status using your secret key:

```bash
curl -X GET https://api.viarosandbox.com/v1/transactions/tx_9182374b12c8 \
  -u sk_test_live_secret_key_12345:
```

## Supported Payment Methods & Regions

| Category | Providers / Channels | Regions Covered |
| :--- | :--- | :--- |
| **Mobile Money** | MTN MoMo, Orange Money, Moov Africa, Express Union Mobile, Airtel Money, M-Pesa | Cameroon (CEMAC), Côte d'Ivoire & Senegal (UEMOA), Ghana, Kenya, Uganda, Rwanda |
| **Cards** | Visa, Mastercard, American Express (via Stripe & Flutterwave) | Worldwide (135+ currencies) |
| **Digital Wallets** | PayPal | Global |
| **Manual USSD** | Automated SMS-reconciled merchant code transfers (`*126*4*...#`, `#150*4*1*...#`) | CEMAC / UEMOA fallback resilience |
| **Bank Transfer** | NIP, ACH, SEPA, Virtual Bank Accounts | Nigeria, International Wire |
