Welcome to the **Pursar Developer Portal**. Pursar is an enterprise-grade financial infrastructure platform designed following modern, developer-first standards (pioneered by Stripe). Pursar unifies mobile money operators across West, Central, and East Africa, global card processing, settlement ledgers, automated reconciliation, and identity compliance into a single cohesive API.

## Architectural Principles

1. **Stripe-Standard API Conventions**:
   Every endpoint uses consistent resource naming, predictable JSON response envelopes (`object`, `id`, `data`, `status`), standard ISO 4217 currency codes, and RFC 7807 error structures.
2. **Standard Authentication**:
   Supports standard HTTP Basic Auth (`curl -u sk_test_...:`) as well as Bearer tokens (`Authorization: Bearer sk_...`).
3. **Idempotency**:
   Pass an `Idempotency-Key` header with any POST request to prevent double-charges and ensure safe automatic retries.
4. **Resilient Webhook Infrastructure**:
   Every state change publishes signed webhook events (`whsec_...`) with cryptographic replay prevention.
