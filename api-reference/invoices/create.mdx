---
title: "Create an Invoice"
api: "POST /invoices"
description: "Create and dispatch an invoice to collect payment from a customer."
---

Creates a new invoice for a customer. Once finalized, an invoice generates a hosted payment URL (`hosted_invoice_url`) where the customer can select their preferred payment method.

---

### Request Body

<ParamField body="customer_id" type="string" required>
  The ID of the customer who will be billed (`cus_...`).
</ParamField>

<ParamField body="amount" type="integer | string" required>
  The total amount due on the invoice.
</ParamField>

<ParamField body="currency" type="string" required>
  Three-letter ISO currency code (`XAF`, `XOF`, `GHS`, `KES`, `USD`, `EUR`).
</ParamField>

<ParamField body="description" type="string">
  An arbitrary description or summary of items included on this invoice.
</ParamField>

<ParamField body="due_date" type="string">
  The date on which payment for this invoice is due (ISO 8601 format, e.g. `2026-11-20`).
</ParamField>

<ParamField body="auto_advance" type="boolean" default="true">
  Controls whether Pursar will automatically finalize and send the invoice.
</ParamField>

