---
title: "List Invoices"
api: "GET /invoices"
description: "Returns a list of invoices issued by your business."
---

Returns a paginated list of invoices. Invoices are returned in reverse chronological order.

---

### Query Parameters

<ParamField query="limit" type="integer" default="10">
  A limit on the number of objects to be returned, between `1` and `100`.
</ParamField>

<ParamField query="status" type="string">
  Filter invoices by status: `draft`, `open`, `paid`, `uncollectible`, or `void`.
</ParamField>

<ParamField query="customer" type="string">
  The ID of the customer whose invoices you want to retrieve.
</ParamField>

---
