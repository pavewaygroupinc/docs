---
title: "List Customers"
api: "GET /customers"
description: "Returns a paginated list of your customers."
---

Returns a list of your customers, ordered by most recently created.

---

### Query Parameters

<ParamField query="limit" type="integer" default="10">
  A limit on the number of objects to be returned, between `1` and `100`.
</ParamField>

<ParamField query="email" type="string">
  Filter customers matching a specific email address.
</ParamField>

---

### Code Examples

<CodeGroup>

```bash cURL
curl -G https://api.viarosandbox.com/v1/customers \
  -u sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG: \
  -d limit=10
```

```python Python
import requests

url = "https://api.viarosandbox.com/v1/customers"
auth = ("sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG", "")

print(response.json())
```
