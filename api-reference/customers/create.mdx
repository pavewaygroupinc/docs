---
title: "Create a Customer"
api: "POST /customers"
description: "Creates a new customer object to track payments, payment methods, and subscriptions."
---

Customer objects allow you to track multiple payments, invoices, and subscriptions that belong to the same person or organization.

---

### Request Body

<ParamField body="name" type="string" required>
  The customer's full name or business entity name.
</ParamField>

<ParamField body="email" type="string" required>
  The customer's primary email address for sending receipts and invoices.
</ParamField>

<ParamField body="phone" type="string">
  The customer's primary phone number in international E.164 format (e.g., `+237670000001`).
</ParamField>

<ParamField body="description" type="string">
  An arbitrary string that you can attach to a customer object.
</ParamField>

<ParamField body="metadata" type="object">
  Key-value pairs for storing arbitrary custom attributes (e.g., internal user ID, membership tier).
</ParamField>
