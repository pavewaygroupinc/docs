---
title: "Retrieve a Customer"
api: "GET /customers/{id}"
description: "Retrieve detailed profile information about a specific customer."
---

Retrieves the details of an existing customer using their unique customer identifier (`cus_...`).

---

### Path Parameters

<ParamField path="id" type="string" required>
  The unique identifier of the customer to retrieve (`cus_...`).
</ParamField>

---

### Code Examples

<CodeGroup>
```bash cURL
curl -G https://api.viarosandbox.com/v1/customers/cus_9f1a2b3c4d5e \
  -u sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG:
```

```python Python
import requests

url = "https://api.viarosandbox.com/v1/customers/cus_9f1a2b3c4d5e"
auth = ("sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG", "")

response = requests.get(url, auth=auth)
print(response.json())
```

```javascript Node.js
const axios = require('axios');

async function getCustomer() {
  const response = await axios.get('https://api.viarosandbox.com/v1/customers/cus_9f1a2b3c4d5e', {
    auth: {
      username: 'sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG',
      password: ''
    }
  });

  console.log(response.data);
}

getCustomer();
```
