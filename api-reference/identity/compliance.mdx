Pursar maintains enterprise-grade Anti-Money Laundering (AML), Counter-Terrorist Financing (CTF), and Know Your Business (KYB) compliance across all supported African regional jurisdictions (CEMAC / COBAC, UEMOA / BCEAO, Bank of Ghana, Central Bank of Kenya).

You can use the Compliance API to programmatically inspect your business tier limits, regulatory status, and outstanding verification requirements.

---

### Retrieve Compliance Status

`GET /compliance/status`

Retrieves the current compliance standing and processing tier limits for your business.

### Code Examples

<CodeGroup>
```bash cURL
curl -G https://api.viarosandbox.com/v1/compliance/status \
  -u sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG:
```

```python Python
import requests

url = "https://api.viarosandbox.com/v1/compliance/status"
auth = ("sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG", "")

response = requests.get(url, auth=auth)
print(response.json())
```

```javascript Node.js
const axios = require('axios');

async function getComplianceStatus() {
  const response = await axios.get('https://api.viarosandbox.com/v1/compliance/status', {
    auth: {
      username: 'sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG',
      password: ''
    }
  });

  console.log(response.data);
}

getComplianceStatus();
```

`GET /compliance/summary`

  -u sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG:
