---
title: "Create a Payout"
api: "POST /payouts"
description: "Send an on-demand payout from your available Pursar balance to a registered payout destination."
---

Initiate an on-demand payout from your available balance to a registered bank account or mobile money destination.

---

### Request Body

<ParamField body="amount" type="integer | string" required>
  The amount to disburse (e.g. `100000`).
</ParamField>

<ParamField body="currency" type="string" required>
  Three-letter ISO currency code (`XAF`, `XOF`, `GHS`, `KES`, `USD`, `EUR`). Must match the destination currency.
</ParamField>

<ParamField body="payout_method_id" type="string" required>
  Identifier of the registered payout method (`pm_...`).
</ParamField>

<ParamField body="description" type="string">
  An arbitrary string describing the payout for reconciliation statements.
</ParamField>

<ParamField body="metadata" type="object">
  Key-value pairs for internal accounting or payroll reference tags.
</ParamField>

---

### Code Examples

<CodeGroup>
```bash cURL
curl -X POST https://api.viarosandbox.com/v1/payouts \
  -u sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG: \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 100000,
    "currency": "XAF",
    "payout_method_id": "pm_bank_afriland_01",
    "description": "Weekly merchant payout"
  }'
```

```python Python
import requests

url = "https://api.viarosandbox.com/v1/payouts"
auth = ("sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG", "")

payload = {
    "amount": 100000,
    "currency": "XAF",
    "payout_method_id": "pm_bank_afriland_01",
    "description": "Weekly merchant payout"
}

response = requests.post(url, auth=auth, json=payload)
print(response.json())
```

```javascript Node.js

        password: ''

  );

  console.log(response.data);

createPayout();
```
