---
title: "List Payouts"
api: "GET /payouts"
description: "Returns a list of existing payouts sent from your Pursar account."
---

Returns a paginated list of existing payouts sent from your account. Payouts are ordered by creation date, with the most recently initiated payout appearing first.

---

### Query Parameters

<ParamField query="limit" type="integer" default="10">
  A limit on the number of objects to be returned, between `1` and `100`.
</ParamField>

<ParamField query="status" type="string">
  Filter payouts by status: `pending`, `in_transit`, `paid`, or `failed`.
</ParamField>

<ParamField query="currency" type="string">
  Filter payouts by currency code (`XAF`, `XOF`, etc.).
</ParamField>
