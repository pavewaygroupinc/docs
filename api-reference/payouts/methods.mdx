---

Payout Methods represent external bank accounts, mobile money wallets, or international recipient details linked to your Pursar business profile for withdrawals and disbursements.

---

### List Payout Methods

Retrieve all configured payout destinations for your account.

`GET /payout_methods`

### Code Examples

<CodeGroup>

```bash cURL
curl -G https://api.viarosandbox.com/v1/payout_methods \
  -u sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG:
```

```python Python
import requests

auth = ("sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG", "")

print(response.json())
```
