---
title: "Create a Product"
api: "POST /products"
description: "Create a new product in your business catalog."
---

Creates a new product object. Products can be linked to prices, payment links, and subscription tiers.

---

### Request Body

<ParamField body="name" type="string" required>
  The product's name, meant to be displayable to the customer.
</ParamField>

<ParamField body="description" type="string">
  The product's description, meant to be displayable to the customer.
</ParamField>

<ParamField body="active" type="boolean" default="true">
  Whether the product is currently available for purchase.
</ParamField>

<ParamField body="metadata" type="object">
  Key-value pairs for internal SKU or inventory tracking.
</ParamField>

---

```python Python
import requests

url = "https://api.viarosandbox.com/v1/products"
auth = ("sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG", "")

payload = {
    "name": "Standard Developer Plan",
    "description": "Monthly recurring developer license",
    "active": True

response = requests.post(url, auth=auth, json=payload)
print(response.json())
```

```javascript Node.js

        password: ''
      }
    }
  );

  console.log(response.data);
}

createProduct();
```
