---
title: "List Transactions"
api: "GET /transactions"
description: "Returns a list of transactions that have been processed by your business."
---

Returns a paginated list of transactions. Transactions are returned in reverse chronological order, with the most recent transactions first.

---

### Query Parameters

<ParamField query="limit" type="integer" default="10">
  A limit on the number of objects to be returned. Limit can range between `1` and `100`.
</ParamField>

<ParamField query="status" type="string">
  Filter transactions by status: `successful`, `pending`, `failed`, or `requires_action`.
</ParamField>

<ParamField query="currency" type="string">
  Filter transactions by three-letter ISO currency code (`XAF`, `XOF`, `GHS`, `KES`, etc.).
</ParamField>

<ParamField query="customer_id" type="string">
  Filter transactions belonging to a specific customer ID.
</ParamField>

<ParamField query="starting_after" type="string">
  A cursor for pagination. An object ID defining your place in the list.
</ParamField>
