---
title: "Create a PaymentIntent"
api: "POST /payment_intents"
description: "Creates a new PaymentIntent object representing a customer payment journey."
---

A **PaymentIntent** guides you through the process of collecting a payment from your customer. We recommend using PaymentIntents rather than direct charges for scenarios requiring complex customer authentication (such as 3D Secure cards or interactive mobile money authorization), multi-channel payments, and frontend checkout sessions.

### Authentication

Pursar follows the **Stripe standard HTTP Basic Authentication** format. Pass your Secret Key as the Basic Auth username (with an empty password), or in the `Authorization: Bearer` header.

---

### Request Body

<ParamField body="amount" type="integer | string" required>
  Amount intended to be collected in the currency's standard units or minor units.
</ParamField>

<ParamField body="currency" type="string" default="XAF">
  Three-letter ISO currency code (`XAF`, `XOF`, `GHS`, `KES`, `USD`, `EUR`).
</ParamField>

<ParamField body="payment_method_types" type="array">
  The list of payment method types enabled for this payment:
  - `mobilemoneyxaf`: Central African CEMAC mobile money (MTN, Orange, EU)
  - `mobilemoneyxof`: West African UEMOA mobile money (Orange, MTN, Moov, Wave)
  - `ghanamobilemoney`: Ghana mobile money (MTN, Telecel, AT)
  - `mpesa`: Kenya M-Pesa
  - `card`: International and local debit/credit cards (Visa, Mastercard, Verve)
  - `banktransfer`: Local real-time bank transfers
</ParamField>

<ParamField body="customer_name" type="string">
  Customer's full name.
</ParamField>

<ParamField body="customer_email" type="string">
  Customer's email address for notifications and digital receipt delivery.
</ParamField>

<ParamField body="phone" type="string">
  Customer's phone number with international country prefix (e.g., `+237671234567`).
</ParamField>

<ParamField body="description" type="string">
  An arbitrary description string displayed on receipts and buyer checkout headers.
</ParamField>

<ParamField body="merchant_reference" type="string">
  Your internal order or invoice ID. Automatically generated if omitted.
</ParamField>

<ParamField body="metadata" type="object">
  Custom key-value pairs stored alongside the PaymentIntent.
</ParamField>

```python Python
import requests

api_key = "sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG"
base_url = "https://api.viarosandbox.com/v1"

response = requests.post(
    f"{base_url}/payment_intents",
    auth=(api_key, ""),
    json={
        "amount": 10000,
        "currency": "XAF",
        "payment_method_types": ["mobilemoneyxaf", "card"],
        "customer_name": "Fatou Ndiaye",
        "customer_email": "fatou@example.com",
        "description": "Order #4810 Enterprise Subscription"
    }
)

intent = response.json()
print("Payment Intent ID:", intent["data"]["id"])
print("Client Secret:", intent["data"]["client_secret"])
print("Checkout URL:", intent["data"]["checkout_url"])
```
