---
title: "Refunds"
api: "POST /refunds"
description: "Issue full or partial refunds for successful transactions and list historical refunds."
---

When you want to return funds to a customer, you create a Refund. Refunds can be full or partial.

Funds are refunded directly back to the customer's original payment method (e.g. their MTN/Orange Mobile Money wallet or credit card).

---

## Create a Refund

<ParamField body="transaction_id" type="string" required>
  The ID of the original successful transaction (`tx_...`).
</ParamField>

<ParamField body="amount" type="integer | string">
  The amount to refund. If omitted, Pursar issues a full refund of the original transaction amount.
</ParamField>

<ParamField body="reason" type="string">
  String indicating the reason for the refund: `requested_by_customer`, `duplicate`, `fraudulent`, or `other`.
</ParamField>

<ParamField body="metadata" type="object">
  Key-value pairs for internal customer service or ticketing reference.
</ParamField>

### Code Examples

<CodeGroup>
```bash cURL
curl -X POST https://api.viarosandbox.com/v1/refunds \
  -u sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG: \
  -H "Content-Type: application/json" \
  -d '{
    "transaction_id": "tx_4a1b2c3d4e5f",
    "amount": 10000,
    "reason": "requested_by_customer"
  }'
```

```python Python
import requests

url = "https://api.viarosandbox.com/v1/refunds"
auth = ("sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG", "")

payload = {
    "transaction_id": "tx_4a1b2c3d4e5f",
    "amount": 10000,
    "reason": "requested_by_customer"
}

response = requests.post(url, auth=auth, json=payload)
print(response.json())
```

```javascript Node.js
const axios = require('axios');

    'https://api.viarosandbox.com/v1/refunds',

      transaction_id: 'tx_4a1b2c3d4e5f',
      amount: 10000,
      reason: 'requested_by_customer'
    },
    {
      auth: {
        username: 'sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG',
        password: ''
      }
    }
  );

  console.log(response.data);
}

createRefund();
```

## List Refunds

`GET /refunds`

Returns a paginated list of all refunds issued by your account.

```bash cURL
curl -G https://api.viarosandbox.com/v1/refunds \
  -u sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG:
```
