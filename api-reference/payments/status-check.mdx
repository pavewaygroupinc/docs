---
title: "Check Payment Status"
api: "GET /public/payment-intents/{id}/status"
description: "Lightweight endpoint for frontend polling of payment status."
---

Use this endpoint to poll the current status of a PaymentIntent directly from your frontend, checkout page, or mobile app while a customer is completing payment.

### Query Parameters

<ParamField query="client_secret" type="string" required>
  The `client_secret` returned when the PaymentIntent was created. Required for public access.
</ParamField>

### Path Parameters

<ParamField path="id" type="string" required>
  The unique ID of the PaymentIntent.
</ParamField>

---

### Gateway Active Verification (Server-to-Server)

If you need your backend to actively verify the status directly against upstream gateways (Flutterwave, Stripe, PayPal) and update local records, use:

```http
PATCH /v1/payment-verification/{reference}/verify
Authorization: Bearer sk_live_...
```

### Response

Returns the current status and basic transaction info.

<ResponseField name="status" type="string">
  The current status: `requires_action`, `processing`, `succeeded`, `failed`, `canceled`.
</ResponseField>

<ResponseField name="amount" type="string">
  The transaction amount.
</ResponseField>

<ResponseField name="currency" type="string">
  The currency code.
</ResponseField>

<ResponseField name="id" type="string">
  The unique transaction ID.
</ResponseField>

<ResponseExample>

{

  "data": {
