---
title: "Direct Mobile Money Charge"
api: "POST /charges/mobile-money"
description: "Initiate an instantaneous mobile money charge prompt across MTN, Orange, Moov, Wave, M-Pesa, and Express Union."
---

The Direct Mobile Money Charge endpoint allows your backend to initiate a push payment directly to a customer's mobile money wallet without requiring them to visit a hosted web page. 

Upon receiving this request, Pursar routes the transaction to the optimal regional telco aggregator and triggers an interactive USSD / STK push on the customer's mobile device asking them to authorize the payment with their mobile wallet PIN.

### Authentication

Pursar follows the **Stripe standard HTTP Basic Authentication** format. Pass your Secret Key as the Basic Auth username (with an empty password), or in the `Authorization: Bearer` header.

---

### Request Body

<ParamField body="amount" type="integer | string" required>
  The amount to charge. Supports integer values (e.g., `25000`) or string representations (e.g., `"25000"`).
</ParamField>

<ParamField body="currency" type="string" required>
  Three-letter ISO currency code. Supported currencies include:
  - `XAF`: Central Africa (Cameroon, Gabon, Chad, CAR, Congo)
  - `XOF`: West Africa (Côte d'Ivoire, Senegal, Benin, Burkina Faso, Mali, Togo)
  - `GHS`: Ghana
  - `KES`: Kenya
  - `UGX`: Uganda
  - `RWF`: Rwanda
</ParamField>

<ParamField body="phone" type="string" required>
  The customer's mobile money phone number formatted with international calling code (e.g., `+237671234567`, `+2250102030405`, `+254712345678`).
</ParamField>

<ParamField body="customer_name" type="string">
  The customer's full name (e.g., `"Amara Diallo"`). Automatically mapped to first and last names.
</ParamField>

<ParamField body="customer_email" type="string">
  The customer's email address for receipt dispatch.
</ParamField>

<ParamField body="description" type="string" required>
  An arbitrary string describing the purchase displayed on statements and notifications.
</ParamField>

<ParamField body="merchant_reference" type="string">
  Unique order or invoice reference from your system. If omitted, Pursar generates a unique transaction reference automatically.
</ParamField>

<ParamField body="country" type="string">
  Two-letter ISO 3166-1 alpha-2 country code (`CM`, `CI`, `SN`, `GH`, `KE`, etc.). 
  
  *Recommended to omit*: Pursar automatically detects the country from the phone number calling prefix.
</ParamField>

<ParamField body="network" type="string">
  Mobile operator identifier (`MTN`, `ORANGE`, `MOOV`, `WAVE`, `MPESA`, `EXPRESS_UNION`).
  
  *Recommended to omit*: Pursar automatically identifies the telco network based on the cellular prefix.
</ParamField>

<ParamField body="fee_bearer" type="string" default="merchant">
  Specifies who absorbs the transaction processing fee:
  - `merchant`: Processing fees are deducted from the merchant payout balance.
  - `customer`: Processing fees are added on top of the charged amount.
</ParamField>

<ParamField body="metadata" type="object">
  Key-value pairs for storing custom data on the transaction.
</ParamField>

curl -X POST https://api.viarosandbox.com/v1/charges/mobile-money \
  -u sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG: \
  -H "Content-Type: application/json" \

```python Python
import requests

url = "https://api.viarosandbox.com/v1/charges/mobile-money"
api_key = "sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG"

payload = {
    "amount": 25000,
    "currency": "XAF",
    "phone": "+237671234567",
    "customer_name": "Amara Diallo",
    "customer_email": "amara@example.com",
    "description": "Invoice #104 Premium License",
    "metadata": {
        "order_id": "ord_88291"
    }
}

response = requests.post(url, auth=(api_key, ""), json=payload)
data = response.json()
print("Transaction ID:", data["data"]["id"])
print("Status:", data["data"]["status"])
```
