---
title: "Payment Methods Discovery"
api: "GET /payment_methods"
description: "Discover available payment options, regional telcos, and calculate transaction processing fees."
---

The Payment Methods API allows your application to programmatically discover which payment channels (Mobile Money operators, Cards, Bank Accounts, PayPal) are active in a specific country and calculate transaction processing fees.

---

## List Supported Payment Methods

`GET /payment_methods`

### Query Parameters

<ParamField query="country" type="string" default="CM">
  Two-letter ISO 3166-1 alpha-2 country code (`CM`, `CI`, `SN`, `GH`, `KE`, `UG`, `RW`).
</ParamField>

---

### Code Examples

<CodeGroup>
```bash cURL
curl -G https://api.viarosandbox.com/v1/payment_methods \
  -u sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG: \
  -d country=CM
```

```python Python
import requests

url = "https://api.viarosandbox.com/v1/payment_methods"
auth = ("sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG", "")

response = requests.get(url, auth=auth, params={"country": "CM"})
print(response.json())
```

```javascript Node.js
const axios = require('axios');

  const response = await axios.get('https://api.viarosandbox.com/v1/payment_methods', {

getPaymentMethods();
```

## Calculate Transaction Fees

`GET /payment_methods/fee/{payment_method}/{currency}/{amount}`

Calculate the exact processing fee and net payout for an anticipated transaction.

### Path Parameters

<ParamField path="payment_method" type="string" required>
  Payment method identifier (`mobile_money`, `card`, `bank_transfer`).
</ParamField>

<ParamField path="currency" type="string" required>
  Three-letter ISO currency code (`XAF`, `XOF`, `GHS`, `KES`, `USD`).
</ParamField>

<ParamField path="amount" type="number" required>
  The transaction gross amount.
</ParamField>

---

### Code Examples

```bash cURL
curl -G https://api.viarosandbox.com/v1/payment_methods/fee/mobile_money/XAF/25000 \
  -u sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG:
```

### Response

  "fee": 500,

  "net_amount": 24500,
  "total_payable": 25000
}
