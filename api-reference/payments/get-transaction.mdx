---
title: "Retrieve a Transaction"
api: "GET /transactions/{id}"
description: "Retrieve complete audit and financial details for a specific transaction."
---

Retrieves the details of an existing transaction using its unique identifier (`tx_...`).

---

### Path Parameters

<ParamField path="id" type="string" required>
  The unique ID of the transaction to retrieve.
</ParamField>

---

### Code Examples

<CodeGroup>
```bash cURL
curl -G https://api.viarosandbox.com/v1/transactions/tx_4a1b2c3d4e5f \
  -u sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG:
```

```python Python
import requests

url = "https://api.viarosandbox.com/v1/transactions/tx_4a1b2c3d4e5f"
auth = ("sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG", "")

response = requests.get(url, auth=auth)
print(response.json())
```

```javascript Node.js
const axios = require('axios');

async function getTransaction() {
  const response = await axios.get('https://api.viarosandbox.com/v1/transactions/tx_4a1b2c3d4e5f', {
    auth: {
      username: 'sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG',
      password: ''
    }
  });

  console.log(response.data);
}

getTransaction();
```
