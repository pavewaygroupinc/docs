---
title: "Retrieve a Transaction"
api: "GET /transactions/{id}"
description: "Retrieve complete audit and financial details for a specific transaction by transaction ID, payment reference, or merchant reference."
---

Retrieves the details of an existing transaction. In accordance with Stripe-standard developer ergonomics and cross-border payment practices, you can query by any of the following identifiers in the URL path:
1. **Transaction ID** (e.g. `060b061c-730a-4ba6-a71d-d34a51e37cb7` or `tx_...`)
2. **Gateway Payment Reference** (e.g. `pay_fe0f4aa967bf` or `PWG_...`)
3. **Your Custom Merchant Reference** (e.g. `ord_test_104`, `inv_ref_104`)

---

### Path Parameters

<ParamField path="id" type="string" required>
  The unique transaction identifier, gateway payment reference (`pay_...`), or merchant reference (`merchant_reference`) of the transaction to retrieve.
</ParamField>

---

### Code Examples

#### 1. Retrieve by Merchant Reference (Stripe Standard)

<CodeGroup>
```bash cURL (Merchant Reference)
curl -G https://api.viarosandbox.com/v1/transactions/inv_ref_104 \
  -u sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG:
```

```bash cURL (Payment Reference)
curl -G https://api.viarosandbox.com/v1/transactions/pay_fe0f4aa967bf \
  -u sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG:
```

```python Python
import requests

# Retrieve using your custom merchant reference or gateway payment reference
url = "https://api.viarosandbox.com/v1/transactions/inv_ref_104"
auth = ("sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG", "")

response = requests.get(url, auth=auth)
print(response.json())
```

```javascript Node.js
const axios = require('axios');

async function getTransaction() {
  // Query by custom merchant reference, payment reference, or UUID
  const response = await axios.get('https://api.viarosandbox.com/v1/transactions/inv_ref_104', {
    auth: {
      username: 'sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG',
      password: ''
    }
  });

  console.log(response.data);
}

getTransaction();
```
