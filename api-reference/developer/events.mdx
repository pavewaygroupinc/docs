---
title: "Events"
api: "GET /events"
description: "Inspect the append-only audit trail of events emitted across your Pursar ecosystem."
---

Events are our way of letting you know when something interesting happens in your account. When an event occurs, Pursar creates an `Event` object and sends it to all configured webhook endpoints.

You can also poll or query the `/events` endpoint to audit past activities, inspect delivery status, or recover missed events.

---

### Query Parameters

<ParamField query="limit" type="integer" default="10">
  A limit on the number of objects to be returned, between `1` and `100`.
</ParamField>

<ParamField query="type" type="string">
  Filter events by specific event type (e.g. `payment_intent.succeeded`, `charge.successful`).
</ParamField>
