title: "API Keys"
api: "GET /api_keys"
description: "Inspect, manage, and audit API keys issued to your business."
---

API keys are used to authenticate requests between your application and the Pursar API.

Pursar issues distinct keys for your Sandbox and Live environments:
- **Publishable keys** (`pk_test_`, `pk_live_`): Intended for public client-side applications, websites, mobile apps, and Checkout SDKs.
- **Secret keys** (`sk_test_`, `sk_live_`): Must be kept confidential on your secure backend server. Never expose secret keys in client-side code, public GitHub repositories, or mobile app binaries.

---

### List API Keys

`GET /api_keys`

Returns all active API keys provisioned for your business.

### Code Examples

<CodeGroup>
```bash cURL
curl -G https://api.viarosandbox.com/v1/api_keys \
  -u sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG:
```

```python Python
import requests

url = "https://api.viarosandbox.com/v1/api_keys"
auth = ("sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG", "")

response = requests.get(url, auth=auth)
print(response.json())
```

```javascript Node.js
const axios = require('axios');

async function listApiKeys() {
  const response = await axios.get('https://api.viarosandbox.com/v1/api_keys', {
    auth: {
      username: 'sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG',
      password: ''
    }
  });

  console.log(response.data);
}

listApiKeys();
```
