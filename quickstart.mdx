## Step 3: Make your First API Request

Let's initiate a direct Mobile Money charge for 25,000 XAF to an MTN Cameroon mobile wallet:

<CodeGroup>
```bash cURL
curl -X POST https://api.viarosandbox.com/v1/charges/mobile-money \
  -u sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG: \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 25000,
    "currency": "XAF",
    "phone": "+237671234567",
    "customer_name": "Amara Diallo",
    "customer_email": "amara@example.com",
    "description": "Quickstart Test License #101"
  }'
```

```python Python
import requests

url = "https://api.viarosandbox.com/v1/charges/mobile-money"
auth = ("sk_test_uLsofsae3tB9Izwgeuy0Mxbh4JIxUPSG", "")

payload = {
    "amount": 25000,
    "currency": "XAF",
    "phone": "+237671234567",
    "customer_name": "Amara Diallo",
    "customer_email": "amara@example.com",
    "description": "Quickstart Test License #101"
}

response = requests.post(url, auth=auth, json=payload)
print(response.json())
```

```javascript Node.js

testCharge();
```

## Step 4: Listen for Webhooks

To update your database and unlock digital products when payments succeed, register a webhook listener at `POST /webhook_endpoints`. Pursar delivers HMAC SHA-256 signed event payloads (`charge.successful`, `payment_intent.succeeded`).

Check the [Webhook Verification Guide](/api-reference/webhooks/verification) for full signature validation examples in Python, Node.js, and PHP.
